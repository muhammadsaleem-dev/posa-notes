16.3 Do Patterns Still Matter in the Age of GenAI?

1. High-Density Prompts for LLMs

Prompting an LLM with “Implement a payment processor using Strategy and Factory Method with bounded queues” yields modular, production-ready code. Without pattern vocabulary, LLMs generate monolithic, spaghetti procedural code.

2. Architectural Guardrails Against AI Hallucinations

AI can generate syntax rapidly, but it lacks spatial systemic awareness. Patterns provide structural boundaries that prevent AI-generated code from violating the Open-Closed and Single Responsibility principles.

3. Humans Still Own Architecture & Review

Engineers in the AI era spend less time typing boilerplate syntax and much more time conducting architectural reviews, evaluating trade-offs, and enforcing package stability metrics ($I, A, D$).

16.5 Questions for Self-Study

Exam Reflection How does knowledge of architectural patterns change the role of a software engineer when using AI coding assistants?

The engineer shifts from a "code typist" to a system architect and auditor.

Instead of manually implementing boilerplate loops and getters, the engineer specifies the system decomposition, selects the appropriate patterns to balance conflicting forces, and audits the AI's output to ensure it does not introduce design smells (rigidity, fragility, cycles). Patterns become the high-level specification language between humans and AI.
