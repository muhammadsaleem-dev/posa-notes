The Dominus & Graham Critique

Are Patterns Flaws in Languages?
Mark Dominus’ Central Thesis: "Design patterns are signs of weakness in programming languages. When we see a pattern, it usually means that the language was not powerful enough to express the abstraction directly." — Mark Dominus (Design Patterns in Perl).
Paul Graham’s Corollary: "This practice is not only common, but a recognized part of computer science: it is called this pattern or that pattern. A pattern means: I have written this same code fifty times in fifty different programs because my language won't let me abstract it into a library function." — Paul Graham (Revenge of the Nerds).

Functional Quicksort & Lambdas in Python

Replacing the Strategy Class Hierarchy
🐍 Python Quicksort with Comparison Lambdas (Exam Task)
< 15 Lines 
# Functional Quicksort taking array and comparison predicate
def quicksort(arr, comp):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    # Partitioning using list comprehensions and comparison lambda
    left = [x for x in arr[1:] if comp(x, pivot)]
    right = [x for x in arr[1:] if not comp(x, pivot)]
    return quicksort(left, comp) + [pivot] + quicksort(right, comp)

# Strategy Lambdas (No class hierarchies needed!)
comp1 = lambda a, b: a < b  # Ascending sort
comp2 = lambda a, b: a > b  # Descending sort

# Execution
data = [5, 2, 9, 1, 7, 6, 3]
print(quicksort(data, comp1))  # [1, 2, 3, 5, 6, 7, 9]
print(quicksort(data, comp2))  # [9, 7, 6, 5, 3, 2, 1]

Question 1: Mark Dominus’ Critique of Design Patterns 4 Points

Mark Dominus stated: "Design patterns are signs of weakness in programming languages." Explain this statement with a concrete example comparing Java and Python!

Model Answer:

Dominus argues that when a programming language lacks sufficient abstraction mechanisms, developers must repeatedly write manual boilerplate patterns to achieve basic flexibility:

  • Classic Java / C++: To customize a sorting algorithm, the language forces the creation of an interface (Comparator) and concrete implementation classes (the Strategy Pattern) because methods cannot exist outside of classes.
  • Python / Functional Languages: Functions are first-class citizens. You pass a lambda or function directly to sort(key=...). The entire Strategy pattern hierarchy is replaced by a built-in language feature. Thus, the pattern existed solely to work around Java's lack of first-class functions.
Question 2: Python Quicksort with Lambdas 8 Points

Given the Python quicksort signature def quicksort(arr, comp):, define the quicksort function using list comprehensions and define the comparison lambdas comp1 (for ascending order) and comp2 (for descending order)!

Model Answer: 
def quicksort(arr, comp):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    left = [x for x in arr[1:] if comp(x, pivot)]
    right = [x for x in arr[1:] if not comp(x, pivot)]
    return quicksort(left, comp) + [pivot] + quicksort(right, comp)

# Ascending comparison (elements less than pivot go left)
comp1 = lambda a, b: a < b

# Descending comparison (elements greater than pivot go left)
comp2 = lambda a, b: a > b
