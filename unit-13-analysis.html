Analysis Patterns: Martin Fowler’s Quantity & Idioms

Master domain modeling rigor, eliminating Primitive Obsession via Martin Fowler's Quantity Pattern, and understanding low-level language idioms like C++ RAII vs. Java AutoCloseable.

1

Martin Fowler’s Quantity Pattern

Eliminating Primitive Obsession
The Problem: Primitive Obsession Representing domain quantities using raw numeric primitives (e.g. double length = 50.0;). Code loses all information about units of measurement (meters vs feet, EUR vs USD), leading to catastrophic errors (such as the 1999 Mars Climate Orbiter crash caused by mixing imperial pound-force-seconds with metric Newton-seconds).
Fowler's Quantity Solution: "Represents a value that is associated with a unit of measurement. A Quantity object encapsulates both an amount (number) and a Unit object." Arithmetic operations on quantities automatically handle conversion or reject dimensionally incompatible operations.
2

Minimal Architecture & Clean Code

Type-Safe Quantity Record
📏 Clean Java Quantity Implementation
< 25 Lines 
public enum Unit {
    METER(1.0), KILOMETER(1000.0), FOOT(0.3048);
    private final double baseFactor;
    Unit(double baseFactor) { this.baseFactor = baseFactor; }
    public double toBase(double val) { return val * baseFactor; }
    public double fromBase(double val) { return val / baseFactor; }
}

public record Quantity(double amount, Unit unit) {
    public Quantity add(Quantity other) {
        double totalBase = unit.toBase(amount) + other.unit.toBase(other.amount);
        return new Quantity(unit.fromBase(totalBase), unit);
    }
}

// Client usage:
Quantity a = new Quantity(100, Unit.METER);
Quantity b = new Quantity(1, Unit.KILOMETER);
Quantity result = a.add(b); // 1100 Meters! Transparent and type-safe!

Programming Idioms: RAII vs. AutoCloseable

Resource Lifecycle Management
IDIOM COMPARISON Deterministic Destruction vs. Garbage Collection
C++ RAII (Deterministic)

Resource Acquisition Is Initialization: Bound to stack scope. Destructors execute automatically the instant stack frames unwind, guaranteeing immediate resource cleanup (locks, file handles, sockets) without explicit try/finally.

Java AutoCloseable

Because Java lacks stack destructors, it uses the try-with-resources language construct. Any class implementing AutoCloseable has its close() method invoked at block exit.

Question 1: Primitive Obsession & The Quantity Pattern 4 Points

Why does representing financial amounts or physical measurements as primitive double variables represent an architectural risk, and how does Martin Fowler's Quantity pattern resolve this?

Model Answer:
  • Risk: Bare numeric primitives strip away unit dimensions. Code cannot verify whether two numbers are measured in the same unit before performing operations (e.g. adding 100 USD to 100 JPY, or adding meters to feet), causing silent logical corruption.
  • Resolution: The Quantity pattern binds an amount with a Unit object in an immutable value object. Arithmetic methods (e.g. add()) automatically convert units to a common base or reject operations between incompatible dimensions at compile-time.
