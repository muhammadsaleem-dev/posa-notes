PILLAR 1 OF 8 · INTENT & MOTIVATION

Domain Rigor: Eliminating Bare Primitives

In 1999, NASA lost the \$327 million Mars Climate Orbiter because one team modeled thrust as pound-seconds while another modeled Newton-seconds. Using a bare primitive double thrust = 5.0; carries no dimension. Analysis patterns bind mathematical quantities to physical and financial units.

Quantity Pattern Intent

Represent a physical or monetary magnitude by binding an exact numerical amount with its associated measurement unit into an immutable Value Object.

PILLAR 4 OF 8 · DESIGN PRINCIPLES

Immutability & Value Objects

Value Object Semantics

Quantities possess no identity; equality is determined strictly by value (e.g. 5 meters equals 5 meters). They are immutable.

Schema Extensibility (Observation)

Instead of adding columns to relational tables whenever new health metrics arise, Observations capture dynamic phenomena generically.

Idiom RAII (Resource Management)

Resource acquisition binds to object creation; automatic deterministic destruction prevents memory and handle leaks.

PILLAR 5 OF 8 · IMPLEMENTATION MECHANICS

Java 17+ Records & Dimension Enforcing

Quantity.java · Java Record Value Object
public record Quantity(BigDecimal amount, Unit unit) {
    public Quantity {
        Objects.requireNonNull(amount, "Amount cannot be null");
        Objects.requireNonNull(unit, "Unit cannot be null");
    }

    public Quantity add(Quantity other) {
        if (!this.unit.isCompatible(other.unit())) {
            throw new IllegalArgumentException("Dimensional mismatch: Cannot add " + unit + " to " + other.unit());
        }
        Quantity converted = other.convertTo(this.unit);
        return new Quantity(this.amount.add(converted.amount()), this.unit);
    }
}
PILLAR 6 OF 8 · COSTS & TRADE-OFFS

Architectural Trade-offs

✅ Domain Benefits
  • Impossible to accidentally add Euros to Dollars or meters to seconds.
  • Value Object immutability eliminates multi-threaded race conditions.
  • Observations allow adding patient telemetry without SQL migrations.
⚠️ Architectural Costs
  • Heap object allocation overhead compared to bare primitive doubles.
  • Complex ORM mapping (e.g. JPA `@Embeddable` or separate unit columns).
  • Observation pattern queries require SQL joins across metadata tables.

Prof. Schäfer Exam Traps: Primitive Obsession

🚨 Frankfurt UAS Exam Trap #1: Primitive Obsession Anti-Pattern

Question: "Why is modeling financial balance as `double balance` a critical design smell?"
Model Answer: Two fatal reasons: (1) Binary floating-point math causes rounding inaccuracies (e.g. `0.1 + 0.2 == 0.30000000000000004`), corrupting financial ledgers; (2) Primitive obsession strips currency context—code can accidentally add ¥500 JPY to \$500 USD without compiler error. The Quantity pattern binds `BigDecimal` with a `Currency` Value Object.

Standard: JSR-385 (Units of Measurement API), Fowler's Analysis Patterns.

● Stage 01 · Martin Fowler's Quantity Pattern

Primitive Obsession & The Mars Climate Orbiter

The most notorious software engineering failure of the 20th century occurred on September 23, 1999, when NASA's Mars Climate Orbiter burned up in the Martian atmosphere. The root cause: Ground navigation software generated thruster firing commands in pound-seconds (English customary unit), while the orbiter's trajectory software expected Newton-seconds (metric SI unit).

OrbiterThruster.java · The Primitive Obsession Trap
// ANTI-PATTERN: Bare primitives convey zero dimensional meaning!
public class RocketThruster {
    public void fire(double impulse) {
        // Did caller pass Newton-seconds or pound-seconds?
        // 1 pound-second = 4.44822 Newton-seconds!
        // A factor of 4.45 error plunged the orbiter directly into the planet!
        this.velocity += impulse / mass;
    }
}
🧠 Key Takeaways: Quantity Modeling Axioms
Bind Amount + Unit

A magnitude without its unit of measurement is incomplete data. Wrap amount and unit into a single immutable Value Object.

Enforce Dimensional Arithmetic

Throw runtime or compile-time exceptions when attempting to add incompatible dimensions (e.g. Kilograms to Meters).

BigDecimal for Finance

Never represent monetary amounts as IEEE 754 floating-point float or double primitives.

● Stage 02 · Dynamic Domain Modeling

Measurement & Observation Patterns

In healthcare applications, modeling patient records with hardcoded class fields (e.g., patient.getBloodPressure(), patient.getCholesterol()) requires modifying the database schema and class files whenever doctors introduce new medical diagnostics. Martin Fowler's Observation pattern decouples entities from variable measurements.

The Observation Data Structure

An Observation links an Entity (e.g. Patient #1042) to a PhenomenonType (e.g. "Systolic Blood Pressure") and a Quantity (e.g. 120 mmHg) recorded at an exact instant in time. New medical metrics are registered dynamically as database rows in a dictionary table rather than code changes.

● Stage 04 · Language Idioms

Programming Language Idioms: C++ RAII vs Java AutoCloseable

An idiom is a low-level pattern specific to a programming language syntax. While design patterns are universal across object-oriented languages, idioms leverage particular compiler mechanics.

C++: RAII (Resource Acquisition Is Init)

Resources (heap memory, mutex locks, file descriptors) are acquired in the constructor and released deterministically in the destructor when exiting scope (even during exceptions).

Java: Try-With-Resources

try (InputStream in = new FileInputStream(...)) guarantees close() is invoked on any AutoCloseable object, eliminating manual `finally` boilerplate.

Exam Drill 1 Why must a Quantity object be modeled as an immutable Value Object? (10 Exam Points)

Model Answer (Prof. Schäfer 1.0 Standard):

Quantities represent conceptual magnitudes (like the number 5 or \$100 Euros), not mutable physical entities.

  1. Prevention of Unintended Side Effects: If a Quantity were mutable, calling account.setBalance(balance.multiply(2)) could inadvertently mutate the balance of other objects sharing that reference.
  2. Thread Safety: Immutable objects are inherently thread-safe without synchronized locks, enabling safe concurrent reading across multiple threads.
  3. Mathematical Correctness: Arithmetic operations (e.g. q1.add(q2)) return a fresh Quantity instance representing the sum, preserving the integrity of operands.
Exam Drill 2 Distinguish between an Architectural Pattern, a Design Pattern, and an Idiom. (6 Exam Points)

Hierarchical Taxonomy:

  • Architectural Pattern (Highest Level): Governs the fundamental macro-structure of an entire software system or subsystem. Technology and language independent (e.g. Pipes & Filters, MVC, Microservices).
  • Design Pattern (Mid Level): Refines the components and relationships between classes/objects within a subsystem. Independent of programming language syntax (e.g. Strategy, Observer, Factory Method).
  • Programming Idiom (Lowest Level): A low-level pattern specific to a single programming language's syntax and runtime mechanics (e.g. RAII in C++, Try-With-Resources in Java, Context Managers in Python).
Exam Drill 3 How does the Observation Pattern solve schema migration problems in relational databases? (4 Exam Points)

Model Answer:

Instead of executing `ALTER TABLE Patient ADD COLUMN blood_pressure FLOAT;` every time medical requirements evolve, the Observation pattern models measurements as dynamic rows:

Each row in the Observation table stores an Entity ID, a Phenomenon Type ID (pointing to a metadata dictionary), a Timestamp, and a Quantity value. New metrics are added simply by inserting a new row into the dictionary table with zero database downtime or code compilation.
