13.3 Martin Fowler’s Quantity Pattern

Never represent physical or financial quantities as bare integers or floats.

The Catastrophe: In 1999, NASA’s \$327 million Mars Climate Orbiter was lost because one engineering team used imperial units (pound-seconds) while another used metric units (Newton-seconds). A bare double thrust = 5.0; carries no dimension!

The Quantity Pattern: Bind an amount with its associated Unit (Currency, Meter, Kilogram, Second) into an immutable Value Object.

Measurement & Observation Patterns

Instead of modifying a Patient class to add bloodPressure, cholesterol, and heartRate attributes, the Observation pattern captures clinical or telemetry measurements dynamically: an Observation records an ObservationType, a Quantity, an observer, and a timestamp. New health metrics can be introduced without database schema migrations.

13.7 Programming Language Idioms

Idioms are patterns expressed within a specific programming language syntax.

C++: RAII

Resource Acquisition Is Initialization: Resources (memory, socket, mutex) are bound to object lifetime; destructors execute automatically when leaving scope.

Java: Try-With-Resources

try (InputStream in = ...) automatically calls close() on any AutoCloseable object, preventing resource leaks.

13.11 Questions for Self-Study

Exam Drill Why should a Quantity object be modeled as an immutable Value Object?

Quantities represent conceptual values (like the number 5 or $100 Euros). Mutating a quantity in place (e.g., changing $100 to $200) can cause unexpected side effects across all entities referencing that instance.

Immutability guarantees thread safety, allows safe sharing across multiple business entities, and ensures operations like qty1.add(qty2) return a fresh instance rather than corrupting existing state.
